# Synthetic Stasis demo data

These files contain deterministic, fictional data for UI testing. They are not measurements and must not be used for health decisions.

Import both CSV files through **Import from a file → Import from WHOOP**. The daily file contains 42 days ending 2026-08-01; the workout file contains 12 fictional sessions.

The app records these rows as imported WHOOP snapshots, keeping them distinct from on-device 1 Hz derivation. Real band-derived days take priority on overlap.
