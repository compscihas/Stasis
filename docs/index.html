Your health data, analyzed locally.

Stasis AI connects directly to WHOOP 4.0 over Bluetooth, stores records in on-device SQLite, and derives health analytics on the phone. An optional self-hosted LLM and backend mirror can be enabled explicitly.

No account or server is required. Health data leaves the phone only for a provider and scope the user configures and consents to. Not affiliated with WHOOP, Inc.

Private by default

  • BLE sync and analytics remain available offline.
  • Self-hosted mirror upload is off by default and idempotent.
  • The AI Coach reads allow-listed derived views only.
  • Firebase diagnostics are disabled unless the developer and user enable them.
