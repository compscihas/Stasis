Stasis AI Privacy Policy

Effective 1 August 2026.

Stasis AI stores WHOOP records, derived metrics, profile data, journals, routes, AI history, and settings on the phone. On-device SQLite remains the source of truth and normal app use requires no server.

Optional self-hosted services

Mirror upload occurs only after a backend and scope are configured, explicit health-data consent is enabled, and synchronization is initiated. Derived scope excludes raw sensor tables and GPS routes. Full-database scope includes sensitive raw health data. Failed uploads stay queued locally and use idempotency keys.

The AI Coach sends prompts and approved derived results—or a bounded derived JSON context—to the configured LLM. It never exposes an unrestricted database handle, raw sensor tables, or GPS routes. Tool-mode writes require confirmation.

Credentials and transport

API keys and bearer tokens use the platform Keychain/Keystore. Use authenticated HTTPS in production. Explicit private-network HTTP support is intended for trusted development networks only.

Diagnostics

Firebase diagnostics are disabled by default and require a developer-owned Firebase project plus user opt-in. The Stasis build does not configure or transmit to original project infrastructure.
